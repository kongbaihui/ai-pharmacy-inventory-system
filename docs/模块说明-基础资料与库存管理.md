# AI 医院药品进销存信息管理系统 —— 基础资料与库存管理部分

本目录包含以下内容：药品分类、药品信息、供应商信息三个基础资料模块，库存盘点、库存预警、药品有效期与过期药品清理四个库存管理模块，以及配套的数据库脚本和系统设计文档。代码严格沿用若依（RuoYi-Vue）代码生成器风格，可直接复制进项目中运行。

## 一、目录结构

```

├── main
│   ├── java/com/ruoyi/system

```

## 三、核心业务规则

1. 库存变更统一入口：所有改变库存数量的操作（盘点盈亏、过期清理）都调用 `IMedStockService.adjustStock`，该方法在同一事务中更新库存数量并写入库存流水，出入库、退库业务同样按此规则处理，保证库存数据一致。
2. 库存预警规则：库存不足与库存积压依据药品信息中的库存下限、库存上限判断；近效期与已过期依据批次有效期和药品信息中的临期预警天数判断；同一药品、批次、类型在未处理状态下不重复生成预警。
3. 有效期规则：批次剩余数量为 0 时批次状态为已清理；有效期已过为过期；有效期进入药品设定的临期天数范围为临期。
4. 盘点规则：新增盘点单时自动带出批次库存作为账面数量，录入实盘数量后自动计算盈亏；审核时按盈亏数量调整库存与批次数量，并生成盘点调整流水；已审核的盘点单不能修改和删除。
5. 过期清理规则：清理数量不能大于批次剩余数量；非报损方式要求批次已过期；确认清理后扣减库存与批次数量并生成过期清理流水，已确认的记录不能删除。

## 四、部署步骤（简要）

详细步骤见 `docs/部署与使用说明.md`。

1. 执行 `sql/01_med_schema.sql` 建表并初始化数据。
2. 执行 `sql/02_med_menu.sql` 生成菜单与按钮权限。
3. 将 `main/java/com/ruoyi/system` 下的代码复制到项目的 `ruoyi-system` 模块同名包下。
4. 将 `main/resources/mapper/system` 下的 XML 复制到项目对应的 mapper 目录。
5. 将 `vue/api/system` 与 `vue/views/system` 下的文件复制到前端工程对应目录。
6. 重启后端服务，刷新前端页面，在角色管理中勾选新菜单权限后即可使用。
